# Stacker
## Purpose
- Stacker is a simple unity game made for passing the time and seeing how high up you can stack the blocks, but be careful the tower may fall and you'll need to restart.

## How to play 
- Requirements
  - Unity 6000.0.26f1

1. fork this repository or download the project zip
2. Open Unity Hub
3. Open the project from the project directory in Unity Hub
4. Navigate to the sample scene in Scenes/SampleScene
5. Click play in the unity edior
6. Enjoy!!
